# CloudWubi 规则库使用与贡献指南

本仓库存放 CloudWubi 的核心语言资源：五笔拆字编码、构词文法、测试用例。
**它是去中心化共建的公共资产**，任何志愿者可贡献，由 CI 自动校验后并入主库。

## 授权

- 本仓库所有数据、文档采用 **CC-BY 4.0** 协议
- 可自由复制、分发、修改，保留署名即可

## 目录结构

```
cloudwubi-rules/
├── README.md              # 本文件
├── wubi86_basic.txt       # 基础 86 五笔编码表（阶段1使用）
├── CONTRIBUTING.md        # 贡献规范（仓库级）
└── tests/                 # 测试用例（CI 校验用，阶段2建设）
```

## 数据文件格式

每行一条记录，`#` 开头为注释：

```
编码 汉字 [汉字...]
```

示例：
```
wq  你 您
g   一
gggg 王
```

## 校验规则（CI 自动执行）

1. 编码必须为 1~4 位小写字母 a~y
2. 每行至少 1 个汉字
3. 编码不得重复（同编码追加为重码候选，需人工确认）
4. 汉字必须为合法 Unicode 中文字符

## 如何贡献

1. Fork 本仓库
2. 修改 `wubi86_basic.txt` 或新增行业词库文件
3. 提交 Pull Request
4. CI 自动校验 → 社区评审 → 合并

## 阶段规划

- 阶段1：基础高频字（当前）
- 阶段2：完整 86 五笔码表 + 构词文法
- 阶段3：行业专业词库（创业BP、编程、法律等）
- 阶段4：生僻字、异体字、多语种混合
